# Tip Calculator

A simple tip calculator application.

## Features

-   Calculates tip based on bill amount and tip percentage.
-   Allows splitting the bill among multiple people.

## Usage

1.  Enter the bill amount.
2.  Enter the tip percentage.
3.  Enter the number of people to split the bill (optional).
4.  Calculate the tip and total amount.
